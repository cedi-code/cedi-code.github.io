Interactive 2D Gaussian splatting for WebGPU, following the
original [3D Gaussian Splatting paper](https://arxiv.org/pdf/2308.04079)

With this project I learned about/implemented:
- WebGPU
- Gaussian Splatting
- Radix Sort
- Adam

I tried to explain and show my approaches in the following [blog](https://cedi-code.github.io/webgpu2dsplatting/journey-primitive.html)
