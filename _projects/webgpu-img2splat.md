Interactive Image to Gaussian splatter for WebGPU, following the same ideas as in the original [3D Gaussian Splatting paper](https://arxiv.org/pdf/2308.04079)

With this project I learned about/implemented:
- WebGPU
- Gaussian Splatting
- Radix Sort
- Adam

I tried to explain and show my approaches in the following [blog](https://cedi-code.github.io/webgpu-img2splat/journey-intro.html)
